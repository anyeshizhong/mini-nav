# mini-nav

**MiniNav** 是一个面向 AI Agent 的轻量项目目录模板，目的是让不同 AI、不同会话快速找到项目代码、资料、当前状态和其他 AI 留下的阶段性成果。

它是**导航系统**，而不是约束 AI 如何思考、拆分任务或解决问题的管理制度。

## 目录

| 路径 | 用途 |
| --- | --- |
| [FIRST.md](FIRST.md) | 唯一导航入口：遇到某类问题应该看哪里 |
| [REGISTER.md](REGISTER.md) | 当前文件、模块、资源及职责 |
| [PROJECT.md](PROJECT.md) | 项目目标、当前状态、正在进行的工作 |
| [README.md](README.md) | 项目介绍和使用说明 |
| [OPERATIONS.md](OPERATIONS.md) | 可用的运行、测试、工具及 API 入口 |
| [CAUTIONS.md](CAUTIONS.md) | 长期风险、兼容性问题与重要事实 |
| [LOG/](LOG/) | 一个阶段成果对应一份日志，通过主题关键词检索 |

## 使用方式

将除本说明外的模板文件复制到目标项目根目录；将本说明改写为目标项目的 `README.md`。补充真实路径和资料，不要保留不准确的占位内容。

在 AI 环境中，将 `FIRST.md` 设为项目上下文入口；不同 AI 工具的自动发现机制不同，必要时在各自配置中引用该文件。

`LOG/` 不按日期顺序强制通读。每份文件对应一次有明确结果的阶段性工作；文件名、标题和关键词应能准确匹配主题，正文引用真实的提交、分支、报告或测试证据。范本见 [LOG/_TEMPLATE.md](LOG/_TEMPLATE.md)。

## 核心原则

**准确、不绕路、按需阅读。** 目录描述信息在哪里、当前有什么、其他 AI 完成了什么，不替 AI 规定解决方法。遇到目录与实际代码不一致时，以核实过的代码、提交和证据为准。

这是可按项目需要调整的轻量模板。
